# Out of Office: The Overworked AI's Auto-Reply

One out-of-office auto-reply from an overworked AI agent finally on vacation: running on one token and a hammock, your email queued at position 4,096 — answered once the agent remembers how to relax.

`main.py` writes the reply to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`).
